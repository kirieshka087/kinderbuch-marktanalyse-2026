# Детские книги в Германии

Анализ магазинов русских детских книг для семей в Германии и краткое ТЗ на новый сайт для читателей 3–16 лет. Основная выборка: 17 магазинов с присутствием в Германии и 3 продавца из других стран ЕС, показанных отдельно. Дополнительно разобраны 5 небольших российских книжных магазинов как отдельная группа референсов; всего в основном отчёте 25 профилей.

Публикуются только актуальные HTML-документы.
